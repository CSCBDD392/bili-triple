# B站三连（@local/bili-triple）

给当前 DSH 加一个左侧栏入口的小工具：扫码登录 B 站，然后在设置里指定某些 UP 主，**他们的每一期视频都自动三连（点赞 + 投币 + 收藏）**；不想全自动时，也可以像「刷B站」那样自己挑视频——**先挑指定 UP 主的视频，再挑其他视频**，勾好一条条给。

## 装在哪、用什么

| 东西 | 位置 |
| --- | --- |
| 插件代码 | 这个目录（`index.js` 宿主侧 + `client.js` 界面 + `py_ops.py` Python 助手） |
| 自己的数据 | `%USERPROFILE%\.dsh\bili-triple\`（`config.json` 规则、`history.jsonl` 记录、`bili_credential.json` 本次登录） |
| Python 运行环境 | 优先复用「刷B站」装好的 `.dsh\bili-duty\.venv`（已带 `bilibili-api-python`）；找不到时会去找本机 Python，可在设置页「本地环境」里手动指定解释器路径 |
| B 站登录 | 本插件扫码后会写自己的 `bili_credential.json`；没登录过时直接借用「刷B站」的登录态，两边的登录互不覆盖（本插件「退出登录」只删自己那份） |

## 三种用法

### 1. 左侧栏 → B站三连 → 挑视频

- **指定 UP 主**：填 UID 或直接贴 `space.bilibili.com/xxx` 主页链接 → 拉到他的投稿列表（最新 / 最多播放 / 最多收藏三种排序）。
- **其他视频**：关键词搜索（最新 / 最多播放 / 综合 / 弹幕），或者排行榜前 N 条。
- **收藏夹**：从自己的收藏夹里翻。
- **按视频找**：贴 BV 号 / av 号 / 视频链接，先看它现在点过赞、投过币、收过藏没有。

勾选后的视频会攒在一个「已勾选」篮子里（切标签页不会丢），下面选好「赞 / 币 / 藏」和投几个币，点「给选中的 N 条三连」就执行。

### 2. 设置 → B站三连：让某个 UP 主的每一期视频都三连

1. 「UP 主三连规则」里点「＋ 加一个 UP 主」，填 UID（或主页链接），会显示昵称和头像。
2. 每条规则可以单独设：
   - 赞 / 币 / 藏 开哪几样、投几个币（1 或 2）；
   - 收藏夹（不选就用「默认收藏夹」）；
   - **只给新视频**：第一次巡查只记下现在有哪些视频，之后再上传的才三连（勾掉则连老视频一起补）；
   - 每轮最多补几条 `dailyLimit`。
3. 「其他视频」区：填**额外想三连的 UP 主 UID**（不在上面规则里的），每轮挑几条；没填 UID 时才会退到关键词 / 排行榜 / 热门。
4. 「节奏与额度」：自动巡查开关、间隔多少分钟、每天总共最多三连几条（防超限）、每条之间歇多久。
5. 「本地环境」能看用的是哪个 Python、数据目录在哪、今天已经三连几条。

「现在就巡查一轮」会立刻跑一遍并把过程打出来；「演习模式」只打印不做。

### 3. 我完全点名

只想要「先 UP 主的视频、再其他视频」这个顺序——设置里配 1~N 个 UP 主规则 + 若干「其他 UP 主 UID」，开自动巡查，它就是先做完 UP 主（题主的每期新视频），再从其他 UP 主里挑几条。

## 三连具体做了什么

按顺序：点赞 → 投币 → 收进收藏夹。每一步都先查现状，已经做过的（比如「重复点赞」65006、「已经投过币」、「重复收藏」）算成功而不是报错，所以同一期视频重复跑也安全。碰到的 B 站接口：

- 点赞 `POST /x/web-interface/archive/like`
- 投币 `POST /x/web-interface/coin/add`
- 收藏 `POST /x/v3/fav/resource/deal`
- 查状态 `has_liked()` / `get_pay_coins()` / `has_favoured()`

（B 站自带的「一键三连」接口会由服务端随意决定投几个币、收进哪个收藏夹，所以这里分步做。）

## 接口（宿主侧，全部只接受本机同源请求）

`/api/bili-triple/` 下：`status`、`config`（GET/POST）、`login/start`、`login/poll`、`logout`、`up-videos`、`user-info`、`convert-uid`、`search`、`rank`、`fav-lists`、`fav-content`、`video-state`、`triple`（POST）、`run`（POST）、`history`、`last-run`。

## 注意

- 三连是有副作用的操作（真的会花掉硬币），额度小一些比较稳；演习模式可以先跑几轮看看挑的是不是你想的那些视频。
- 自动巡查只在 DSH Web 开着的时候跑（跟着宿主进程）。
